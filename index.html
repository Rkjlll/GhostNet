SUPPORTED INPUTS

Scan and inspect

Camera scanning uses the browser BarcodeDetector API when supported. Supported formats vary by device and browser. A paired Zebra scanner operating as a keyboard wedge can also type directly into the data field.

DATA SAFETY

Preserve source and provenance

Transformations create a preview, not a silent edit to the scanned source. UPC-A and EAN-13 are checked for format and check digit, but cannot be regenerated or modified as official retail identifiers here. Custom Code 39 output is clearly identified as an internal label.
